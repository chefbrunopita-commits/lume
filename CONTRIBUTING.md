# Contribuir para o Lume

Obrigado por ajudar.

1. Abra uma issue descrevendo o problema ou a ideia.
2. Faça fork e um branch com nome curto (`fix/composer-focus`).
3. Mantenha a interface em português e o código em inglês.
4. Não adicione telemetria, analytics nem chaves de API no repositório.
5. Abra um pull request contra `main`.
